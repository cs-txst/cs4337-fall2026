CS 4337 / Introduction to Computer Vision

Interactive Visualizations

Standalone browser demos that go with the lecture slides and the course notebooks. Every page runs offline from a file, with no installs and no network.

What these are for

Each page takes one idea the slides can only show as a finished picture and puts the parameter that produced it on a control, so the class can watch it move.

How to run them

Open any .html file in a browser, from a folder or a USB stick. There is no build step, no server and no dependency to install.

The numbers are real

Where a page reports a count or a coordinate, it was checked against the same call in OpenCV 4.10 on the same input, not against the page's own arithmetic.

In the classroom

Open one page at a time rather than this index. Each is laid out for a projector with a single idea on screen, and reloading resets every control.

Ask before you show

Every page carries an ASK line on its lecture index. The demos are built for prediction first, reveal second; showing the answer straight away spends the best part of them.

Editing

One file, one demo. The CSS, the JavaScript and any images are inline, so changing a default means opening the file, changing a number and reloading.

Reusing

These are plain HTML pages under no framework. Copy a folder anywhere, serve it from GitHub Pages, or hand a student the single file.
