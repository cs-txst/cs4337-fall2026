Motion Detection Demos

Four interactive pages for Our First Computer Vision Application. Each one opens on its own, runs offline, and prints the OpenCV call behind every control.

One idea per page

Each page isolates a single step of the detector. Reloading a page puts every control back to the value the lecture uses.

They run offline

No network, no installs, no libraries. Every frame of video and every line of code is inside the file, so a copied folder or a USB stick works exactly the same.

Real frames, real numbers

The video pages use frames from the highway clip the course notebook opens. Every count on screen was checked against the same call in OpenCV.

An order that works

The wraparound page first, since everything after it depends on subtracting two frames correctly. Then Two Ghosts. Finding the Car and Two Different Centers both assume you have already seen a thresholded mask.

The central one

Two Ghosts, One Car covers slides 7 through 10. It is the one place the three-frame minimum stops being a formula, and its second tab works through slide 9 on real pixel values.

Editing them

Each file is standalone HTML with its CSS, its JavaScript and its video frames inline. Open one in any editor, change a number, reload. Nothing needs building and nothing needs installing.

Every number is checkable

The differences, thresholds, component counts and centroids on these pages were verified against OpenCV 4.10 on the same frames, so what is on screen is what the notebook produces.
