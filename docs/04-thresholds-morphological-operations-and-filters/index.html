Lecture 04 Demos

Ten interactive pages for Thresholds, Morphological Operations and Filters. Each one opens on its own, runs offline, and prints the OpenCV call behind every control.

One idea per page

Each page isolates a single idea from the lecture. Reloading a page puts every control back to the value the lecture uses.

They run offline

No network, no installs, no libraries. Every image and every line of code is inside the file, so a copied folder or a USB stick works exactly the same.

Every control names its call

The panel at the bottom of each page updates as you move the sliders, so the bridge from the demo to the notebook is always on screen.

An order that works

Threshold Explorer, then Shadow on the Page, then the Morphology Sandbox before the tennis court. For the filtering half: Kernel Playground first, then whichever of the four supporting pages the idea needs.

The central one

The Kernel Playground. It serves the most slides and carries the one idea that comes back in edge detection, in feature descriptors and in every convolutional network after that.

Editing them

Each file is standalone HTML with its CSS and JavaScript inline. Open one in any editor, change a number, reload. Nothing needs building and nothing needs installing.

Every number is checkable

The filters, thresholds and morphology on these pages were verified against OpenCV itself, so the values on screen are the values the notebook produces.
