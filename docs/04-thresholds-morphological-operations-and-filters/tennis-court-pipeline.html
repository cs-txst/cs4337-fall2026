Try this first
Drag the red margin from 10 up to 40. The pipeline never
      says it failed: it keeps returning two blobs. What changes is that the near court has
      broken into pieces, so the second blob is now half a court. Ask the class how they
      would detect that automatically.

    
Why dilate at all
Set the dilation kernel to 1. The red and green regions
      no longer touch, so their overlap is empty and there is nothing to find. The dilation
      is not cosmetic: it is what makes two neighbouring regions share a boundary.

    
The ethics ask
Switch to Blue hard court. The margins were tuned
      on one photograph of one surface. The code still runs, still returns two regions, and
      still draws them confidently, while the components collapse to a third of their size.
      Ask the class what else gets tuned on one population and shipped to everybody.

    
The trap that bites everyone
