Edge Detection Demos

Seven interactive pages for Edge Detection. Each one opens on its own, runs offline, and prints the OpenCV call behind every control.

One idea per page

Each page isolates a single step or a single trap. Reloading a page puts every control back to the value the lecture uses.

They run offline

No network, no installs, no libraries. The photographs and every line of code are inside the file, so a copied folder or a USB stick works exactly the same.

Real photographs, real numbers

The church is the image the course notebook opens; the other photograph is the one on the deck's own slides. Every count on screen was checked against the same call in OpenCV 4.10.

An order that works

The Argument That Eats Your Edges first, because everything after it depends on computing a derivative correctly. Then Sharper or Steadier, then Canny One Step at a Time. Two Thresholds and One Pixel both expand a single step of that pipeline, so they come after it.

The central one

Canny, One Step at a Time covers the whole second half of the deck. It is the only place where the four steps stop being a numbered list and become five pictures you can push around.

Editing them

Each file is standalone HTML with its CSS, its JavaScript and its photographs inline. Open one in any editor, change a number, reload. Nothing needs building and nothing needs installing.

Every number is checkable

The blur kernels, Sobel responses, gradient magnitudes, suppression results and edge counts were verified against OpenCV 4.10 before being printed. Where a page differs from the library on purpose, it says so and gives the measured size of the difference.
