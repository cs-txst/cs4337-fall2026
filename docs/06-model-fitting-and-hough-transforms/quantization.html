The trap runs opposite to intuition
Holding the threshold fixed at 90, the finest setting (ρ = 1 pixel, θ = 1 degree) returns 29 lines. Coarsening ρ to 3 pixels returns 1,159. Coarser bins do not merge lines into fewer answers: they pool votes from lines that were never the same line, so far more cells clear the threshold and the output floods.

    
The two knobs pull apart
Coarsening θ pulls the other way, since there are fewer columns to hold peaks at all. Every bin size needs its own threshold, which is why neither knob can be tuned on its own.

    
Where the lines come from
The scene is the bowling alley photograph from the model fitting slide. Every line drawn here came from cv.HoughLines run at that exact bin size on cv.Canny(gray, 80, 160), precomputed for all 25 combinations; only the accumulator heat map is recomputed in the browser. The threshold is held at 90 throughout so the sliders show what quantization alone does.
