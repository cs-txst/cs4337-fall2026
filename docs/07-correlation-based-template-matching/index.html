Correlation-based Template Matching Demos

Six interactive pages for Correlation-based Template Matching. Each one opens on its own, runs offline, and prints the OpenCV call behind every control.

One idea per page

Each page puts one step of the lecture on a control: the template, the score, the slide, the search, the threshold. Reloading a page puts every control back to the value the notebook uses.

They run offline

No network, no installs, no libraries. The photographs, the 337 faces, the score maps and every line of code are inside the file, so a copied folder or a USB stick works exactly the same.

OpenCV's numbers

Every score map and every best match is cv.matchTemplate output on the notebook's own photos and template. Where a page recomputes a score to follow a slider, it was checked against OpenCV first.

An order that works

Building the Average Face first, because every other page uses its template. Then What the Score Ignores and Six Ways to Score a Match for the score, The Template Slides for the sliding, and Searching Size and Tilt with the second half of the deck. From Scores to Faces closes the lecture.

The central one

What the Score Ignores is where normalized correlation stops being a formula: the same face scores 0.799 as photographed, in shade, and brightened, while the cosine can barely tell it from a patch of trees.

Editing them

Each file is standalone HTML with its CSS, its JavaScript and its data inline. Open one in any editor, change a number, reload. The sources and the build script live in _build/.

Every number is checkable

The measurements come from code/prep-interactive-data.py in the lecture folder, which prints each check as it runs. Where a page recomputes a score in the browser, it matches OpenCV to within 0.0001.
