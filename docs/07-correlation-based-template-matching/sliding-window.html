Why the map is smaller
The template is 60 rows by 50 columns and must fit entirely inside the 417 by 485 photo, so its top-left corner can take only 417 - 60 + 1 = 358 rows and 485 - 50 + 1 = 436 columns. Each score belongs to that corner, not the template's center.

    
One face, many hits
Shift the template one pixel off the face and it still covers nearly the same pixels, so the score barely drops. At 0.6, 69 positions pass; at 0.5, 164. A detector keeps the peak of each clump and suppresses its neighbors.

    
Rows and columns, x and y
cv.minMaxLoc reports the best match as (x, y) = (206, 153). np.unravel_index on the same array returns (row, column) = (153, 206). Both are right, and swapping them draws the box in the wrong place. The map shown is OpenCV's own cv.matchTemplate output.
