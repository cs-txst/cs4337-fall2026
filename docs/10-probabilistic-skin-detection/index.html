Probabilistic Skin Detection Demos

Five interactive pages for Probabilistic Skin Detection: the four detectors side by side with every threshold on a slider, a bell curve that shows how a density can reach 391, the two histograms drawn inside the RGB cube, a histogram you build yourself at any bin count, and Bayes' rule applied to any pixel you click. Each page opens on its own, runs offline, and prints the code behind every control.

The same photos as the notebook

Training frame, test frame and both histograms are the notebook's own files from data/, embedded in each page, so a result seen here comes back by running one cell.

They run offline

No network, no installs, no libraries. A copied folder or a memory stick behaves exactly the same on a classroom projector.

Measured, not asserted

At the notebook's settings the pages keep the same share of frame20 as NumPy does for every model (23.0%, 9.5%, 9.4% and 8.8%), and pixel A's posterior is the 0.986 on the worked-example slide.

Where the data come from

frame2.bmp and frame20.bmp are the notebook's training and test frames, and positive_histogram.npy and negative_histogram.npy its 32 x 32 x 32 skin and non-skin histograms. 10 - Probabilistic Models and Skin Detection/code/make-viz-data.py packs them for these pages.

What these are for

Every result slide shows one threshold on one model. The gap the slides leave is what happens as the threshold, the training data or the prior changes, and that is what these pages show.

Reading the code bar

Every page ends with the code its controls stand for, with the values the controls are currently on highlighted. Paste it into the notebook after its first cells and the same numbers come back.
