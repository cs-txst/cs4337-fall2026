Intro to Machine Learning and Neural Networks Demos

Four interactive pages for learning a classifier from examples: Lecture 12's faces recognized by ten learned templates, three scores turned into probabilities and a loss, a learning rate that creeps, converges, bounces or blows up, and the notebook's spiral network trained live, with and without its ReLU. Each page opens on its own, runs offline, and prints the code behind every control.

The same data as the notebooks

The spiral is notebook 13.1's 300 points with its seed, and every run starts from the notebook's own initial weights, so its settings give its numbers: 49% for the linear classifier, 99% for the 2-layer network. The faces are Lecture 12's database.

They run offline

No network, no installs, no libraries. The networks train in the browser in plain JavaScript, in a second or two.

Measured, not asserted

The pages' losses and accuracies were checked against NumPy running the same steps, and the softmax page's probabilities, losses and gradients against PyTorch's F.softmax and F.cross_entropy.

Where the data come from

The spiral is regenerated with notebook 13.1's code and seed; the faces are data/face_recongition_db. 13 - Intro to Machine Learning and Neural Networks for Vision/code/make-viz-data.py packs them for these pages, with the NumPy and PyTorch numbers they were checked against.

What these are for

The slides show one learning rate, one network size and one set of scores. The gap they leave is what happens as each of them changes, and that is what these pages show.

Reading the code bar

Every page ends with the code its controls stand for, with the values the controls are currently on highlighted. The spiral code runs in notebook 13.1 after its data cell; the face code needs the normalized face arrays of the Lecture 12 notebook.
