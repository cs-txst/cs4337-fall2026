Convolutional Neural Networks Demos

Six interactive pages for the convolutional layer and what is built from it: one filter meeting the three channels of a color photo, output sizes and parameter counts, receptive fields, pooling under small shifts, the notebook's trained network running in the page, and its face classifier turned into a one-pass detector. Each page opens on its own, runs offline, and prints the PyTorch code behind every control.

The notebook's own networks

The learned filters, the CIFAR-10 network and the face classifier are the ones the lecture's notebook trains and saves, with their trained weights, and the photos are CIFAR-10 test photos and the notebook's data/faces.jpg.

They run offline

No network, no installs, no libraries. The convolutions run in the browser in plain JavaScript.

Measured, not asserted

Every page's numbers were checked against PyTorch: the convolution outputs against nn.Conv2d, the class probabilities against the trained network, the receptive fields against autograd, and the face map against the notebook's fully convolutional network.

Parameter Counter

Output size from (N − F + 2P) / S + 1 and the parameter count of one layer, next to a fully connected and a locally connected layer with the same outputs, on a log scale. Presets for every example of the lecture, AlexNet's first layer included.

Receptive Field Explorer

Stack convolutions and pooling layers, click a unit, and light up everything it depends on, down to the pixels of a CIFAR-10 photo. Three 3 × 3 layers against one 7 × 7, the notebook's network, and the first blocks of VGG-16.

The trained CIFAR-10 network of the notebook, running in the page: its six filters, every activation map, and the class probabilities for a test photo. Move or mirror the photo and watch the maps move with it, and the answer change more than you might expect.

Sliding Window vs One Pass

The notebook's 31 × 25 face classifier run over a whole photo twice: window by window, and as a fully convolutional network in one pass. Same map, very different time. Then change the scale and the threshold.

Where the data come from

Lectures/14 - Convolutional Neural Networks (CNNs)/code/make-viz-data.py packs the CIFAR-10 photos and the two networks that code/make-notebook.py trained into _build/data-14.json, with the PyTorch reference numbers the pages were checked against.

What these are for

Planning and self-study: open a page while preparing the slides it serves, or point students to it after class. Each opens on its own; nothing here needs the others.

Reading the code bar

The highlighted values in the code at the bottom of each page are the ones the controls just set. The code assumes the notebook's names (X_test, net, face_net, FaceFCN), so it runs after the notebook's cells.
