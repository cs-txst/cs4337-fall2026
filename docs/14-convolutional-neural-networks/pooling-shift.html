No parameters
Pooling learns nothing: it is a fixed rule, applied to every map separately. It halves the height and the width, so the next layer costs a quarter as much and each of its units covers twice the distance.

    
Roughly where, not exactly where
A shift of one pixel moves every value of the edge map, but a 2 × 2 maximum often stays the same, because the strong value is still inside its block. On these CIFAR-10 photos a one-pixel shift changes the pooled map about a quarter to a third less than the edge map. Shift by 2 and the pooled map simply moves by one cell.

    
Only roughly invariant
An odd shift can carry a strong value across a block boundary, and then the pooled map changes too. Stacked pooling layers make a network tolerant to small shifts, never fully indifferent to them.
