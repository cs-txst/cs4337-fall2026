Deep Learning for Semantic Segmentation: Demos

Six interactive pages for labeling every pixel: why a network shrinks the image and what that costs, how the answer is grown back to full size, what skip connections add, how training proceeds pixel by pixel, and how the output is scored. Most of them use the notebook's street photos and its trained networks. Each page opens on its own, runs offline, and prints the PyTorch code behind its controls.

The notebook's own photos and networks

The photos are test photos of the Penn-Fudan pedestrian dataset, and the probability maps are the ones the notebook's networks produced for them: Lecture 15's ResNet-18 with three different ways back to full size.

They run offline

No network, no installs, no libraries. The upsampling and receptive-field pages compute in the browser and agree with PyTorch on every setting tested; the network outputs were computed beforehand in PyTorch.

Measured, not asserted

IoU, pixel accuracy and the per-pixel loss are computed in the page from the stored maps and the hand-drawn masks, and they match what NumPy computes for the same photos. The feature maps and training snapshots come from one more training run with the notebook's settings.

Where the data come from

Lectures/16 - Deep Learning for Semantic Segmentation/code/make-viz-data.py packs the test photos, their hand-drawn masks, the maps the notebook saved, and the feature maps and training snapshots of code/viz-runs.py into _build/data-16.json, with PyTorch's answers for the two pages that compute in the browser.

What these are for

Planning and self-study: open a page while preparing the slides it serves, or point students to it after class. Each opens on its own; nothing here needs the other.

Reading the code bar

The code at the bottom of each page uses the notebook's names (net, x, truth), so it reads like the notebook's cells.
