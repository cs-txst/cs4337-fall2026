IoU is strict
Shift a perfect box sideways by a fifth of its width and the IoU is already 0.67. Make it 20% larger in each direction and it is 0.69. A box that looks fine to the eye often scores between 0.6 and 0.8.

    
Both errors count
A box that is too large covers the whole object and still loses: the union grows. A box that is too small loses because the intersection shrinks. Only the ratio matters, so IoU does not depend on how big the object is.

    
Neighbors overlap too
Put your box on the other pedestrian. Its IoU with this one is not zero, because the two people overlap. Non-max suppression has to tell such a neighbor from a duplicate using nothing but this number.
